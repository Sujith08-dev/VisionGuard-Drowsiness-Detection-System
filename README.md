# VisionGuard - Real-Time Drowsiness Detection System

## Features
- Real-time face detection
- Eye detection using OpenCV
- Drowsiness monitoring
- Audio alerts
- Screenshot capture
- CSV event logging

## Tech Stack
- Python
- OpenCV
- Pygame

## How It Works
Webcam → Face Detection → Eye Detection → Drowsiness Detection → Alarm → Screenshot → Log

## Installation
pip install -r requirements.txt

## Run
python sleep_detector.py
